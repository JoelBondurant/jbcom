Streaming Charts

The following chart is generated with Vega-Lite. To configure an initial axis range, an initial point is obtained and combined with unionWith in the domain object. The unionWidth property ensures the axis range includes all data upon updates, while the nice property rounds the range. To initialize the async data loading, the vegaEmbed(...).then(asyncStartupHandler) pattern is used. Lastly, to make the chart partially responsive, the width is set to container so the outer div can control chart size.
